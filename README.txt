LUDUS INTELLECTUS — VS Code setup

1. Open this folder in VS Code.
2. Open index.html.
3. Install the VS Code extension "Live Server" by Ritwick Dey.
4. Click "Go Live" in the bottom-right.
5. In the browser, click START GAME.

Controls:
- Move the striker: click/drag near the striker along the baseline.
- Aim: move the pointer around the striker to rotate the aiming guide.
- Power + strike: drag from the striker backward, then release.
- The shot uses simulated carrom physics and pocket detection.
- Correct pocket = +1 point and pole animation.
- Demo mode automatically shoots toward the correct answer.

This version keeps the Antigravity visual layout and implements the playable canvas game in the same HTML file.
