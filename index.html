/ HOW IT WORKS

Seven Steps to Knowledge

A seamless loop of thinking, aiming, and learning — powered by carrom physics and smart sensors.

01💭
Think

Read the Question

A question appears on the player display with four answer options, each mapped to a corner pocket — A, B, C, or D.

02🎯
Aim

Choose Your Pocket

Position the striker along the baseline. Drag to rotate the aiming guide toward the pocket that matches your answer.

03💥
Strike

Release and Shoot

Pull back to set power. Release to fire the striker. The coin collides, bounces, and travels across the board.

04📡
Detect

Pocket Sensor Activates

The moment a coin enters a pocket, the virtual sensor fires and registers which of the four sensors was triggered.

05⚖️
Evaluate

Answer Compared

The pocket label (A/B/C/D) is matched against the correct answer. The ESP32 runs this logic in real time.

06🏆
Score

Points Awarded

Correct pocket → +1 point. Incorrect or no pocket → 0 points. Turn passes to the next player.

07⚙️
Feedback

Pole Rises

The mechanical pole labeled with the detected pocket rises — instant, tactile confirmation of the answer.

/ HARDWARE ARCHITECTURE

The Physical System

Every element of the physical prototype is simulated digitally. Designed for seamless IoT integration.

📡

POCKET SENSORS (A·B·C·D)

IR or hall-effect sensors behind each corner pocket detect when a carrom coin crosses the threshold. Each sensor maps to one answer option.

🤖

ESP32 MICROCONTROLLER

Receives sensor signals via GPIO, runs answer evaluation logic, triggers pole actuators, and pushes state to all four player displays over WiFi/BLE.

⚙️

MECHANICAL POLES (A·B·C·D)

Servo-actuated poles behind each corner handle. Normally retracted. Rise when the corresponding pocket detects a coin — immediate physical feedback.

🖥️

PLAYER DISPLAYS × 4

LCD/OLED screens mounted on each edge of the board, facing each player. Show question, options, turn indicator, and score in real time.

🔌

IoT ABSTRACTION LAYER

SensorInterface, PoleController, DisplayController — simulated now, swappable for real hardware drivers when the physical prototype is built.
